# Raudvatn Valley

> [!note] Player knowledge only
> Facts recorded as revealed in play. No speculation.

The region around **[[Brindelvik]]** — the campaign's starting area. Named for the **Raudvatn** river running through it. The broader region label on the map reads **Askarsoeng**.

![[Raudvatn_Valley.png]]

## Places on the Map

| Place | Notes |
|---|---|
| **[[Brindelvik]]** | Starting town (southeast). Party's home region. |
| **Ardgrind** | Walled/keep site to the east — almost certainly the **"[[Aldgrind]]"** the traveler asked the road toward. *(spelling to confirm)* |
| **Raudaedr** | Settlement to the far west, on the Raudvatn river. |
| **Svarthamarhald** | Fortified settlement, central-north. |
| **The Crooked Lantern** | Waystation/inn on the road, north. |
| **Raudhamar** | Large mountain massif, far west. |
| **Malreth-Khal's Tviaxlir** | Twin peaks, north-central. |
| **Aelbrak-Haugr** | Rocky highland southeast, near Brindelvik. |
| **Holkrunvidr** | Forested region, far northeast. |

## Roads & Rivers
- **Gamulvar-Hrygrr** — the main east–west road across the valley.
- **Raudvatn** — the river the valley is named for.
- **Voelvutradr** — a river/tributary in the north.
